Glaucoma Detection with Explainable AI

Detects glaucoma from clinical retinal fundus images, compares two architectures and flags every mismatch so clinicians can audit the model.

MobileNetV2 98.7% val. acc.Custom CNN 92.6%Live test 9/10
How it works
  • Hillel Yaffe Glaucoma Dataset (clinical fundus images)
  • Benchmarked a custom CNN against MobileNetV2 transfer learning
  • Grad-CAM explainability on MobileNetV2’s final conv layer (work in progress)
  • Clinical-style test dashboard: per-scan prediction, confidence and red mismatch flag
  • Evaluation focused on false negatives — a missed case is an untreated patient
TensorFlowKerasMobileNetV2Grad-CAM

Brain Tumor Classification from MRI

CNN that classifies brain MRI scans as tumor / no tumor, built as a pre-screening aid for radiologists.

78.4% test accuracy253 MRI images
How it works
  • 3-block CNN (32 → 64 → 128 filters) with dropout and a 512-unit dense head
  • Small dataset (253 images), so augmentation and early stopping against overfitting — the honest next step is transfer learning to push accuracy higher
  • Evaluated with confusion matrix and sample prediction visualizations
TensorFlowKerasOpenCVCNN

Real-Time Weed Detection Robot

Edge AI system that tells crops from weeds in a live camera feed, built for smart agriculture.

Real-time on Raspberry Pi 4
How it works
  • YOLOv4 deployed with OpenCV DNN on a Raspberry Pi 4
  • 2 classes (crop, weed), 512×512 input, confidence and NMS thresholds at 0.5
  • Bounding boxes and confidence scores drawn on every frame
